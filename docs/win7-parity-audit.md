# Windows 7 parity audit (Haiku workflow)

Date: 2026-11-08 · Branch: `feat/windows7-aero-redesign` · Workflow run `wf_ca36f0e1-7e8`

## Method

Every agent ran on Haiku 5.5. 16 read-only auditors each took one area and compared the code with
two references: the 7.css source (`node_modules/7.css/dist/gui/*.css`, `7.scoped.css`, upstream
repository) and the Windows 7 UX Interaction Guidelines. Findings were deduplicated by file, line
and category. Then each finding went to three skeptics, each asked to refute it from a different
angle: (1) does the cited code exist and behave as claimed, (2) is the reference value true of 7.css
or Windows 7, (3) is it a deliberate constraint, an accepted difference or too trivial to matter. A
finding stands only when at least two of the three skeptics could not refute it. The skeptics also
re-rated severity; the table uses their rating.

The Opus orchestrator then re-read the cited code for each finding it acted on, before changing anything.

## Need an owner decision

- **#2 (high) Lock screen unlocks on any click or key with no password**: Deliberate for now: the lock screen is a privacy curtain over a live cookie session, not an authentication boundary. A password-gated unlock needs a re-authentication endpoint; this needs an owner decision.
- **#48 (medium) Lock screen lacks the Windows 7 password box, arrow and Switch User controls**: Follows from the lock screen decision.
- **#49 (medium) Logon password field has a show/hide reveal button Windows 7 does not have**: The show/hide password control is a deliberate accessibility affordance and is kept.
- **#53 (medium) Lock screen unlocks on any key or click with no password**: Same as the high-severity lock screen finding above.

## Kept for 7.css parity

- **#5 Every focused push button pulses and stays blue after a mouse click**: 7.css itself pulses every focused push button (`button:focus` shares the `.default` rule), and on Windows 7 the focused button becomes the default button. Kept for parity.

## Open backlog

Most open items are missing Windows 7 features, not defects in existing ones. Examples are the Explorer
navigation pane, tree, search, history and sorting; All Programs and pinned/recent lists in the Start
menu; taskbar grouping and Aero Peek; the window system menu and keyboard move/resize; and the Task
Manager and Notepad menus. Each needs its own design and tests, so none were rushed into this pass.
